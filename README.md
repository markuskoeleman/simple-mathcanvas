# An incredibly simple drawing canvas

## keybinds
| Keybind | Action |
| :--- | :--- |
| `z` | Undo |
| `e` | Erase strokes |
| `i` | Invert contrast |
| `shift` | Hold to draw straight line |
| `space` | Hold space to pan around |
| `h j k l` | Use vim keybinds to jump by 85% of the screen |
| `shift` + `h j k l` | Use vim bindinds to jump by 10% of the screen |
| `Mousewheel` | Zoom the canvas in and out |
